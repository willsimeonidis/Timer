# Timer
📜 Overview
Timer is a minimalist yet expressive time‑calculation web app designed to feel smooth, readable, and timeless — inspired by the light, newspaper‑style aesthetic of your 8H‑News project.
It allows anyone to select any date and time, and instantly see:

How long until that moment (countdown)

How long since that moment (count‑up)

The display updates live every second, with clean animations that mimic the gentle pulse of a phone timer — no milliseconds, no noise, just clarity.

Timer is fully responsive, phone‑friendly, and built to be simple, elegant, and satisfying to use.

✨ Key Features
🕰️ Dual Mode: Count Up & Count Down
Enter any date and time — past or future — and Timer automatically determines whether to count toward or away from that moment.

📊 Multiple Display Formats
Switch between different time representations:

Normal:  
1 year 57 days 4 hours 32 minutes 56 seconds

Seconds

Minutes

Hours

Days

Months (approx)

This makes Timer useful for everything from casual curiosity to precise time measurement.

🎄 Built‑in Presets
A clean preset panel lets users quickly jump to major events:

Christmas

New Year

School Ends

Custom Important Day

Each preset includes a year selector, allowing countdowns for future or past years.

📱 Mobile‑Friendly Layout
Timer is designed to look perfect on phones:

Large, dramatic center timer

Easy‑to‑tap dropdowns

Clean spacing

Smooth animations

🎉 Confetti Celebration
When a countdown reaches zero, Timer triggers a burst of animated confetti and automatically transitions into a count‑up mode — showing how long it has been since the moment passed.
